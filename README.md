## Sobre este repositório

Este repositório é o código do meu site de portfólio, feito com **React + Vite** e publicado automaticamente no GitHub Pages a cada push na `main`.

```bash
npm install
npm run dev      # servidor local em http://localhost:5173/Portifolio/
npm run build    # gera a versão de produção em dist/
```

Todo o conteúdo do site (experiências, projetos, habilidades) fica em [`src/data.js`](src/data.js).
